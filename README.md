
# Step Zone

Mi proyecto será un sitio web para Step Zone, una tienda de tenis dirigida a personas interesadas en adquirir 
calzado deportivo y casual. El sitio permitirá mostrar los diferentes modelos de tenis disponibles, brindar
información sobre la tienda y facilitar los medios de contacto, ayudando a los clientes a conocer los productos 
disponibles de manera rápida y sencilla sin necesidad de acudir personalmente al establecimiento.
